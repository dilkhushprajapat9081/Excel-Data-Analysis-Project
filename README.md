# Student Marksheet Project 📊

यह प्रोजेक्ट मैंने एक्सेल (Excel) पर एक बेहतरीन मार्कशीट बनाने के लिए तैयार किया है। इसमें छात्रों के अंक, कुल योग (Total), प्रतिशत (Percentage) और ग्रेड (Grade) निकालने के लिए फॉर्मूलों का उपयोग किया गया है।

- Average / Percentage फ़ॉर्मूला
